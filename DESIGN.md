# Design references

The [MaxRohowsky gallery](https://github.com/MaxRohowsky/best-github-profile-readme) is the starting point. The linked index takes cues from [Max Rohowsky](https://github.com/MaxRohowsky/maxrohowsky). [Nate Moore](https://github.com/natemoo-re/natemoo-re) uses widget imagery as an entry point rather than an inventory. [Ross Williams](https://github.com/rossjrw/rossjrw) uses image-based interactions to take the reader directly to an action. Here, the top-level projects are artwork and real links; the experiment notes are optional disclosure panels.

The art references [Cameron's World](https://www.cameronsworld.net/) and [classic player skins](https://docs.webamp.org/docs/features/skins/). The console, wireframe, windows, icons and buttons are original SVGs stored in this repository. Card data summarizes the [published evidence](https://github.com/BetoBraga/stochastic-provenance/blob/main/docs/evidence.md). The visual index stays readable if remote widget services are down.

The optional pin is the original [GitHub Readme Stats repository widget](https://github.com/anuraghazra/github-readme-stats#github-extra-pins), themed to match the artwork. It only queries public metadata about Stochastic Provenance. No account activity, saved repositories, access keys, or private data are used. No third-party code is installed in this repository.
