# Design references

The starting point for this revision was [Best GitHub Profile READMEs](https://github.com/MaxRohowsky/best-github-profile-readme). The examples below informed the structure; no source text, artwork, widget code, or service endpoints were reused.

- [Max Rohowsky](https://github.com/MaxRohowsky/maxrohowsky): a signature banner and a compact project index with distinct destinations. Here, the banner also reports a result, and the index tells readers which question each tool lets them test.
- [Nate Moore](https://github.com/natemoo-re/natemoo-re): an opening belief before credentials, and a widget that says something specific about the author. Here, that becomes one engineering belief and a locally hosted SVG with measured results, instead of a music feed.
- [Emil Widlund](https://github.com/emilwidlund/emilwidlund): a short description of who he is and what he is doing. Here, the opening stays focused on the work rather than inventorying technologies.

The same evidence register appears on the [Stochastic Provenance project site](https://betobraga.github.io/stochastic-provenance/). The card is a static snapshot, not live telemetry. See the [evidence notes](https://github.com/BetoBraga/stochastic-provenance/blob/main/docs/evidence.md) for the data and limits. The README uses native GitHub Markdown and a light/dark SVG pair; the project site adds an accessible breakdown of the findings and paths to the paper and code.
