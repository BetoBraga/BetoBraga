# Design references

The [MaxRohowsky collection](https://github.com/MaxRohowsky/best-github-profile-readme) supplied the reusable README patterns: a banner and linked project index ([Max Rohowsky](https://github.com/MaxRohowsky/maxrohowsky)); an opening belief and a distinctive interactive element ([Nate Moore](https://github.com/natemoo-re/natemoo-re)); and a short introduction ([Emil Widlund](https://github.com/emilwidlund/emilwidlund)). This version also uses native GitHub links and disclosure panels. No third-party widget code or endpoints run here.

The current art direction references [Cameron's World](https://www.cameronsworld.net/) for the hand-built personal web and [classic player skins](https://docs.webamp.org/docs/features/skins/) for the tight physical interface. The 88×31 buttons, wireframe aperture, and all interface graphics are original. The aperture is illustration, not experimental data. The companion [research page](https://betobraga.github.io/stochastic-provenance/) uses the same visual language but keeps the research text selectable and adds a keyboard-operable comparison of the two reported workloads.
